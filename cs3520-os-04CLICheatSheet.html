Command Line Cheat Sheet

A quick reference for the commands covered in the CLI tutorial. Use man <command> for full details on any of them.

Navigation

Command What it does
pwd Print your current working directory
cd <dir> Move down into a subdirectory
cd .. Move up to the parent directory
cd / Move to the root directory
cd ~ or cd Move to your home directory
ls List the contents of the current directory
ls <path> List the contents of another directory
ls -l Long listing: permissions, owner, size, modification time
ls -a List all files, including hidden files (names starting with .)

Path symbols: / root directory, ~ home directory, .. parent directory, . current directory. A path starting with / is a full path. Anything else is relative to your current working directory.

Working with Files and Directories

Command What it does
touch <file> Create an empty file (or update its modification time)
mkdir <dir> Create a new directory
mv <src> <dest> Move or rename a file or directory
cp <src> <dest> Copy a file
rm <file> Delete a file (permanently, no confirmation!)
rm -r <dir> Delete a directory and everything in it (careful!)
nano <file> Edit a file in a simple terminal editor

Viewing and Searching

Command What it does
cat <file> Print a file's contents to the terminal
more <file> View a file one page at a time (space = next page, q = quit)
grep '<text>' <file> Print lines in a file that contain the text
grep -r '<text>' <dir> Search all files in a directory and its subdirectories
sort <file> Print a file's lines in sorted order (sort -r reverses)
echo <text> Print text to the terminal
man <command> Read the manual for a command (space = next page, q = quit)

Redirection and Pipes

Syntax What it does
cmd > file Send stdout to a file (overwrites the file)
cmd >> file Append stdout to a file
cmd < file Read stdin from a file instead of the keyboard
cmd1 | cmd2 Connect cmd1's stdout to cmd2's stdin

Example: ls -l | grep 'txt' > results.txt lists files, filters for 'txt', and saves the result to a file. Each command in a pipeline runs as its own process. The OS moves the data between them (inter-process communication).

Processes

Command What it does
ps List the processes in your terminal session (pids, etc.)
sleep <n> Create a process that waits n seconds, then exits
kill <pid> Send a signal to a process to terminate it
cmd & Run a command in the background (shell does not wait)
CTRL-C Send a signal to terminate the foreground process

Remember: every command runs as a child process of your shell. Foreground means the shell blocks and waits for the child. Background (&) means it doesn't.

PATH and Executables

Command What it does
echo $PATH Show the directories the shell searches for commands
echo $PATH | tr ':' '\n' Same, but one directory per line
which <command> Show the full path of a command's executable file

PATH is an environment variable. Child processes inherit it from the shell.

Permissions

Command What it does
chmod u+x <file> Add execute permission for the owner
sudo <command> Run a command as the superuser (root)

Reading ls -l permission strings: -rw-r--r-- = regular file (-), owner can read and write (rw-), group can read (r--), others can read (r--). A d in the first position means directory.

Odds and Ends

Command What it does
exit Terminate the shell process (closes the terminal)
find . -type f -mtime -1 Find files modified in the last 24 hours (from the intro demo)
