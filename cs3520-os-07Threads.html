Threading

A process is a program in execution.

The advantage of using processes is that you can decompose a complex problems into smaller, simpler 'flows of control' that can be managed independently.

If the computer has multiple processors then the processes can work concurrently.

There is considerable overhead associated with creating processes with calls to fork():

  • the entire process image has to be copied (text, data, heap, stack, PCB)
  • the CPU state has to be saved into the new process image
  • in order to share the workload often a communication channels is needed

OS designers have created a more lightweight and efficient mechanism to achieve concurrency.

A thread is a flow of control within a process.

A thread is considered lightweight because when it is created it gets its own call stack used for local variables but shares global variables.

POSIX Threads (Pthreads)

The POSIX threads library (Pthreads) is a standard API for creating and managing threads in C and C++.

Pthreads are mapped one-to-one with kernel threads on modern operating systems (Linux, Windows, macOS).

To create a thread we use the pthread_create() function.

int pthread_create(pthread_t *thread, const pthread_attr_t *attr, void* (*start)(void *), void *arg);

  • pthread_t *thread is a pointer to a thread object. This is used to reference a thread for joining or synchronizing.

  • const pthread_attr_t *attr is a pointer to a thread attributes object.

  • void* (*start) (void *) is a pointer to a function that takes a void pointer as an argument and returns a void pointer. This is the function that will be executed by the thread.

Let's look at function pointers in C++

A thread ends when it returns from its start function.

The return value is a generic void pointer. If you want to return a piece of data you can return a pointer to that data.

Alternatively, pthread_exit(retval) can terminate a thread from anywhere in the call stack, but returning from the thread function is more common.

pthread_exit(void *retval);

A thread can wait for another thread to complete if it has access to its pthread_t object.

int pthread_join(pthread_t thread, void **retval);

This function is used to join a thread.

Example 1

Basic thread creation.

#include <iostream>
#include <unistd.h>
#include <pthread.h> //thread library
#include <string>

using namespace std;

//this function will be called when a thread is created
void* foo(void* arg);

//global variable shared between all threads
string name = "Mark Mahoney";

int main()
{
    //thread identifier
    pthread_t thread1;

    //return value of foo function
    void* thread_result;

    cout<<"Creating a thread"<<endl;

    //create a thread
    //- pass the address of a thread id
    //- a null pointer
    //- the name of a function
    //- a pointer to some data that will get passed in the function
    pthread_create(&thread1, 0, foo, 0);

    cout<<"Waiting for the thread to finish..."<<endl;

    //wait for the thread to finish
    pthread_join(thread1, &thread_result);

    cout<<"Thread finished"<<endl;

    return 0;
}
//--
void* foo(void* arg)
{
    cout<<"\t*** Inside foo() in a new thread *** "<<endl;
    cout<<"\tAccessing the global variable 'name': "<<name<<endl;

    //return a null pointer
    return 0;
}

Example 2

Creating multiple threads and passing specific data into each one.

#include <iostream>
#include <unistd.h>
#include <pthread.h>

using namespace std;

//this function will be called when a thread is created
void* foo(void* arg);

//the number of threads we want to create
const int numThreads = 10;

int main()
{
    //assigned ids of each thread 
    int thread_ids[numThreads];

    //generate ids for each thread
    for(int i = 0;i < numThreads;i++)
    {
        thread_ids[i] = i;
    }

    //array of thread identifiers, one for each thread
    pthread_t threads[numThreads];

    //array of return values of foo function
    void* thread_result[numThreads];

    cout<<"Creating threads"<<endl;

    //create the threads
    for(int i = 0;i < numThreads;i++)
    {
        //create an id and pass it into the thread's function via a parameter
        //pass in the address of an element in the array of ids
        pthread_create(&threads[i], 0, foo, &thread_ids[i]);
        
        //alt pointer syntax
        //pthread_create(&threads[i], 0, foo, thread_ids + i);
    }

    cout<<"Waiting for the threads to finish..."<<endl;

    //wait for the thread to finish
    for(int i = 0;i < numThreads;i++)
    {
        pthread_join(threads[i], &thread_result[i]);
    }

    cout<<"All threads finished"<<endl;

    return 0;
}
//--
void* foo(void* arg)
{
    //cast the void pointer to an int pointer 
    int* p_id = (int*)arg;

    //print the value of id
    cout<<"My id is: "<<*p_id<<endl;

    //return a null pointer (required for methods called from new threads)
    return 0;
}

Example 3

Attempting to use shared data.

#include <iostream>
#include <unistd.h>
#include <pthread.h>

using namespace std;

//this function will be called when a thread is created
void* foo(void* arg);

//global variable shared between all threads
int num = 0;

//the number of threads we want to create
const int numThreads = 10;

int main()
{
    //array of thread identifiers, one for each thread
    pthread_t threads[numThreads];

    //array of return values of foo function
    void* thread_result[numThreads];

    cout<<"Creating threads"<<endl;

    //create the threads
    for(int i = 0;i < numThreads;i++)
    {
        pthread_create(&threads[i], 0, foo, 0);
    }

    cout<<"Waiting for the threads to finish..."<<endl;

    //wait for the thread to finish
    for(int i = 0;i < numThreads;i++)
    {
        pthread_join(threads[i], &thread_result[i]);
    }

    cout<<"All threads finished"<<endl;

    return 0;
}
//--
void* foo(void* arg)
{
    //print the value of num
    cout<<num<<endl;

    //increase the value of the shared num by one
    num++;
    
    //return a null pointer (required for methods called from new threads)
    return 0;
}
